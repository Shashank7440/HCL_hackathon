# Circular: Electronics Return Window (CIRC-2026-07, version 1.0)

## 1 Electronics return window reduced to 7 days
Effective from 2026-08-01, the return window for all ELECTRONICS products is 7 calendar days from the delivery date, counted as defined in Return, Refund and Exchange Policy section 3.1. This circular supersedes RET-POL-2024#3.1 for the ELECTRONICS category. All other categories remain unchanged.

## 2 Reason
This change reflects industry norms for high-value electronics and enables faster refurbishment cycles. No other clause of the Returns Policy is affected.
